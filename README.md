# Padrões de Projeto - Extensão

Este projeto apresenta a implementação de três padrões de projeto da categoria Extensão em Java: Decorator, Iterator e Visitor.

Cada padrão foi desenvolvido em um mini-projeto que simula uma situação do mundo real.

## Padrões implementados

### Decorator
Utilizado em um sistema de pagamentos, permitindo adicionar funcionalidades como taxa de processamento e seguro a um pagamento.

Branch: `decorator`

### Iterator
Utilizado em um carrinho de compras, permitindo percorrer os produtos da coleção de forma sequencial sem acessar diretamente sua estrutura interna.

Branch: `iterator`

### Visitor
Utilizado em um sistema de produtos de uma loja, permitindo realizar operações específicas, como o cálculo de impostos, para diferentes tipos de produtos.

Branch: `visitor`
