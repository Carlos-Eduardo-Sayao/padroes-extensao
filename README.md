# Padrões de Extensão = Iterator

O padrão Iterator fornece uma forma de percorrer os elementos de uma coleção de maneira sequencial sem precisar conhecer sua estrutura interna. Na sua implementação, o Iterator permite acessar os elementos um por um, utilizando operações como `hasNext()` e `next()`.

Neste projeto, o padrão foi utilizado em um carrinho de compras, permitindo percorrer os produtos adicionados ao carrinho sem precisar acessar diretamente a estrutura interna da lista que armazena os produtos.
